# Hệ thống quản lý chi tiêu cá nhân và phân tích thói quen tài chính

## 1. Cài đặt

Mở Terminal/CMD tại thư mục project và chạy:

```bash
pip install -r requirements.txt
```

## 2. Chạy chương trình

```bash
python main.py
```

## 3. Chức năng

- Thêm / xem / sửa / xóa giao dịch
- Tìm kiếm và lọc theo tháng
- Tổng thu, tổng chi, số dư
- Thiết lập ngân sách
- Cảnh báo vượt ngân sách
- Phân tích thói quen chi tiêu
- Biểu đồ cơ cấu, so sánh và xu hướng
- Xuất báo cáo CSV

## 4. Cấu trúc

```text
He_thong_quan_ly_chi_tieu_Python/
│
├── main.py
├── requirements.txt
├── README.md
└── data/

    ├── budgets.csv
    └── (các biểu đồ/báo cáo được tạo sau khi chạy)
```
